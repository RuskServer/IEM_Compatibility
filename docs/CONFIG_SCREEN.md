# 設定画面

Minecraft 26.3 Fabric版。YACL `3.9.7+26.3-fabric` が必須。Mod Menu `21.0.0` は任意で、入れている場合はMOD一覧の設定ボタンから開ける。Mod Menuがない場合もワールド内の `/iemconfig` で開ける。YACL/Mod Menu本体はIEMの配布jarには同梱しない。

## 音響

- 立体音響 ON/OFF
- 壁・床による遮蔽と距離高域減衰 ON/OFF
- OpenALが検出したHRTFプロファイル選択

画面上の編集は保存するまで音響へ反映しない。取消時は適用済み設定を維持する。保存時、音響に変更があった場合だけ設定を書き出して一度サウンドエンジンを読み直す。同じ画面で複数回保存する場合も直前の適用状態と比較する。

## 診断

- 今回の起動中だけ有効なGPU時間表示
- 適用中HRTF・OpenAL拡張対応・処理数（画面を開いた時点の値）
- モノラル／ステレオの定位テストと停止

試聴ボタンは変更を保存し、画面を閉じてからテストする。ワールド外では無効。GPU表示だけを変更しても音声を再読み込みしない。

日本語・英語の表示を用意した。遮蔽の強さなど、音響の固定パラメーターは今回の画面では公開しない。

## 描画の無効化機構を削除

`/iemcore` の登録、`CoreSwitches` 本体、機能無効化用マクロを追加する処理を削除した。設定画面にも代替の無効化項目を設けない。GlslCompilerMixinは通常のMOD連携に必要な `IEM_MOD` の定義だけを維持する。

## 検証

- `./gradlew clean build`
- `JAVA_HOME=/path/to/jdk25 python tools/check_audio_mixins.py`
- 同じコマンドに `--without-modmenu` を追加して、Mod Menuなしの動作も検証

Fabricの実際のクラスローダーでYACL設定モデルを構築し、未保存変更・取消・連続保存・変更なし保存・GPU表示のみの保存・ワールド外でのテスト無効化・Mod Menuの入口を検証する。画面の描画や実際のマウス操作を行うテストではない。レイアウトと試聴はゲーム内で確認する。
