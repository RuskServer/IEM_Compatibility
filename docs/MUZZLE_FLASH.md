# マズルフラッシュの診断

プラグイン・リソースパック・modを対応する版へ更新する。mod経路は `iem:muzzle` の発射信号を受け、フレームUBOの `IemFrameVisor.y` に渡す。

従来の受信時点の状態だけを見る処理では、発射と次tickの消灯が同じ描画前に届くと、一度も点灯しなかった。現在は発射を描画直前まで保持し、初めて採用してから50ms表示する。消灯通知で未描画の発射を消さず、250ms以上古い発射は破棄する。切断時は明示的に状態を消す。

- `/iemmuzzle`: 受信パケット数、発射数、描画用に採用した発射数、待機・表示モード、フレーム値の有無、UBOの反映回数を表示する。採用数は実際のシェーダー出力を保証するものではない。
- `/iemmuzzle test`: サーバー通信を経由せず、腰撃ちの信号を注入する。画作りシェーダーが有効なワールド内で確認する。

射撃後も受信が0なら、プラグインの版とチャンネル登録を確認する。受信と採用が増えるのに見えず、ローカル試験も表示されなければ、パックの版・画作りの有効状態・UBO経路を確認する。

`./gradlew muzzleTest` は点灯・消灯の一括到着、低FPS相当の描画遅延、連射、失効、モード切替、切断時の回収を検証する。
